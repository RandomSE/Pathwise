# Recruiter one-pager

Unzip `Pathwise-recruiter.zip`. Double-click `Pathwise.exe`. That is the whole setup. No Python, no extra files to fill in.

1. On the play screen, choose Recruiter login (candidates stay on this screen and play with no extra steps).
2. Log in or Create account.
3. Set rounds and difficulty.
4. Generate seed.
5. Copy the code and send it to the candidate. They paste it on the play screen.

If this build includes mail settings, a dashboard zip is emailed when a candidate finishes that seed. If mail is off, after a local recruiter session the app shows the full path to `logs_dashboard.html` and can open it.

Do not unpack `_internal` looking for setup files.
